Git / GitHub

这是你自己账号的配置，存在数据卷里（），换镜像不丢。 gh 只装二进制、不带任何凭据 —— 装完第一件事就是来这里填自己的，填完容器里 gh 与 git push 直接可用。

清除已保存的 token

保存后会渲染成 （0600），并顺带写好 git 凭据助手 （credential.helper = !gh auth git-credential），所以容器里 git clone/push 私有仓库不用再输密码。 Token 需要 repo 权限；要看/触发 CI 再加 workflow。
